# Сайт TeacherDesk

Репозиторий сайта TeacherDesk. Страницы верстает студия MOON, на свой сервер сайт выкладывает заказчик.

## Что где лежит

```
site/          готовый сайт. Только эта папка идет на сервер
docs/          ТЗ, ссылки на макеты, памятки
prototype/     архив: прототип из коммерческого предложения, на сервер не нужен
.github/       шаблоны для сдачи страниц и правок
CHANGELOG.md   что сдано и когда
index.html,
404.html       служебные файлы GitHub Pages для прототипа, на сервер не нужны
```

## Как выложить сайт

Скопируйте содержимое папки `site/` в корень сайта на сервере. Больше ничего на сервер не нужно.

Готовое берите из ветки `main` (Code → Download ZIP) или ZIP-архивом из раздела Releases.

## Как сдается работа

1. Каждая страница приходит отдельным Pull Request. В нем ссылка на превью и список, что проверить.
2. Посмотрите страницу. Если все хорошо, напишите в комментарии: «принято».
3. После этого страница попадает в `main`, а в CHANGELOG появляется запись.

## Как оставить правку

Issues → New issue → шаблон «Правка». Одна правка на один Issue, так ничего не потеряется.

## Правки по договору

- Две итерации правок: вехи «Правки 1» и «Правки 2».
- Все, что после них, идет в веху «Доп. работы» по почасовой ставке.
